# F10 — Go modules contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

GOPROXY list/info/mod/zip/latest semantics with escaped paths and canonical module zip validation.

- go: **go1.27.2** ([release/source](https://go.dev/dl/?mode=json)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of immutable module version plus .mod/.info/.zip as one publish. There is no invented go publish command.

## Consume and source support

go mod download/build resolves public or private modules through local/remote/replica sources.

## Resolution policy

package-owner per module path

## Format-specific integrity and metadata

Preserve module path case escaping, version identity and checksums. Public clients retain their configured checksum database; private modules use documented GOPRIVATE/GONOSUMDB settings. Kuvryn Ant is not a checksum database.

## Explicit non-goals

No sumdb authority or VCS hosting. Never disable checksum verification globally to make the proxy work.

## Required client scenarios

- [ ] Resolve a module with uppercase path escapes and a transitive dependency; repeat from warm cache/replica.
- [ ] Reject invalid zip layout, conflicting immutable version or module checksum mismatch; no public fallback for private namespace.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

API only (GOPROXY has no delete; authors retract in go.mod): `DELETE @v/{version}` (the bundle resource). Deletes.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

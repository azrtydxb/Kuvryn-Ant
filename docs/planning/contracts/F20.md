# F20 — R / CRAN contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

CRAN-style source and Windows/macOS binary repository layouts with PACKAGES, PACKAGES.gz and PACKAGES.rds.

- r: **4.6.1** ([release/source](https://cran.r-project.org/src/base/R-4/)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of source/binary packages into explicit R-version/platform channels; generate package indexes after metadata validation.

## Consume and source support

R available.packages/install.packages uses local, remote and replica indexes and package archives.

## Resolution policy

snapshot-owner per platform/R-version repository

## Format-specific integrity and metadata

Keep source/binary identities distinct and preserve dependencies/MD5 metadata alongside internal SHA-256. Binary evidence must run on its native platform.

## Explicit non-goals

CRAN submission/review services and server-side R package builds or install hooks are excluded.

## Required client scenarios

- [ ] Install source plus a dependency on Linux and binary fixtures on Windows/macOS.
- [ ] Wrong R/platform placement or corrupt archive is rejected; index points only to committed assets.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

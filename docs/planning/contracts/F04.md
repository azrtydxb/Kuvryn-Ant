# F04 — CocoaPods contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

HTTP CDN-style podspec discovery and pod source/archive delivery for CocoaPods 1.17.0.

- cocoapods: **1.17.0** ([release/source](https://api.github.com/repos/CocoaPods/CocoaPods/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of validated podspec JSON plus an immutable source archive or explicit external source reference; regenerate CDN metadata atomically.

## Consume and source support

pod install/update resolves specs and downloads declared source archives; support local, remote CDN cache and replica feeds.

## Resolution policy

package-owner per pod name

## Format-specific integrity and metadata

Keep source hashes and podspec version identity. Full offline seed must materialize referenced source archives; VCS-only references are visibly external and block a complete-offline claim.

## Explicit non-goals

No CocoaPods Trunk account/API clone, general Git hosting or pod repo push endpoint. Publication uses documented admin ingestion; CDN consumption remains a real-client workflow.

## Required client scenarios

- [ ] Ingest podspec/archive; pod install on macOS fetches the selected version from the feed.
- [ ] Conflicting pod version or mismatched archive hash fails; a source-only external dependency is reported in seed preflight.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

Native (`pod trunk delete`): `DELETE pods/{name}/{version}` unlists the version (core `Unlist`); a tombstoned version is never republished.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

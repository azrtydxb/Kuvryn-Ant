# F24 — Swift Package Manager contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Swift package registry protocol v1, scoped identities, releases, manifests and source archives.

- swift: **swift-6.4.1-RELEASE** ([release/source](https://api.github.com/repos/swiftlang/swift/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Swift registry publish uses authenticated immutable version upload and validates archive/checksum/manifest inventory; preserve signatures where supplied.

## Consume and source support

Swift package resolve/download via a configured registry across local/remote/replica sources.

## Resolution policy

package-owner per scope.name

## Format-specific integrity and metadata

Use protocol-supported authentication and retain signing/fingerprint metadata; run macOS and Linux clients against the selected SDK. Source archives are data, not server-executed code.

## Explicit non-goals

General Git hosting and promising compatibility with arbitrary future registry protocol extensions are excluded.

## Required client scenarios

- [ ] Publish and resolve a scoped package with manifest/archive checksums on selected Swift clients.
- [ ] Identity mismatch, corrupt archive and signer/fingerprint mismatch have explicit failures; replica preserves metadata.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

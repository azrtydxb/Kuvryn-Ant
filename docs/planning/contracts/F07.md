# F07 — Conda contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Conda channel subdirectories, .conda and .tar.bz2 packages, repodata.json and compressed representations.

- conda: **26.9.3** ([release/source](https://api.github.com/repos/conda/conda/releases/latest)).
- conda-index: **0.13.0** ([release/source](https://pypi.org/pypi/conda-index/json)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion per channel/platform; extract package metadata without executing content; generate a coherent repodata generation including current_repodata where advertised.

## Consume and source support

conda search/install with noarch and platform packages; proxy indexes and assets as one source snapshot.

## Resolution policy

snapshot-owner per channel/subdir

## Format-specific integrity and metadata

Preserve patched upstream repodata relationships. Local indexing uses validated package metadata. Explicit priority prevents mixing incompatible channel snapshots.

## Explicit non-goals

No conda-build execution or claim of arbitrary repodata patch authoring/signing extensions beyond the selected fixtures.

## Required client scenarios

- [ ] Ingest noarch and platform packages in both supported containers and install a dependency chain.
- [ ] Malformed archive, stale repodata-to-asset mapping and mismatched package checksum fail safely.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

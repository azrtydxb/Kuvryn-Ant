# F14 — npm contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

npm registry packuments, scoped packages, tarball attachments, dist-tags, publish/unpublish subset and token auth.

- npm: **v12.2.1** ([release/source](https://api.github.com/repos/npm/cli/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

npm publish validates package metadata/tarball digest and atomically commits a version. Dist-tag changes and deletion require separate permissions/policy.

## Consume and source support

npm install/view/dist-tag behavior with local/remote/replica packuments; rewrite tarball URLs to authorized feed assets.

## Resolution policy

package-owner per normalized scoped/unscoped name

## Format-specific integrity and metadata

Return integrity metadata matching exact tarball bytes; serialize mutable tag/packument changes. Login/bootstrap provides a machine token compatible with npm configuration, not browser SSO at registry routes.

## Explicit non-goals

Public npm organization/billing APIs, audit advisory service emulation and upstream publishing are excluded.

## Required client scenarios

- [ ] Publish scoped package, move a dist-tag and install a lockfile from cache and replica.
- [ ] Private name cannot fall through upstream; conflicting version/tarball integrity and unauthorized unpublish fail.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

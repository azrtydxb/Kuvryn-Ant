# F02 — Ansible Galaxy contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Galaxy collection API v3 with API-root discovery and asynchronous import status.

- ansible-core: **2.21.5** ([release/source](https://pypi.org/pypi/ansible-core/json)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

ansible-galaxy collection publish uploads a built collection; validate namespace/name/version, archive inventory and dependencies; expose import status until commit.

## Consume and source support

Collection version discovery, dependency resolution and archive delivery for ansible-galaxy collection install; local/remote/replica sources.

## Resolution policy

package-owner per namespace.collection

## Format-specific integrity and metadata

Use a scoped Galaxy API token. Resolve download URLs through authorized source mappings; cancellation or failed import leaves no installable version.

## Explicit non-goals

Legacy Galaxy roles, web-community/social APIs and executing collection code during ingestion are excluded.

## Required client scenarios

- [ ] Publish a collection with a dependency, wait for import, install via one configured server.
- [ ] Invalid archive or unauthorized namespace fails import; a cancelled import is not advertised.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

# F26 — Yum / RPM contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

RPM-MD repomd.xml and primary/filelists/other metadata with repository/package signing and compressed indexes.

- dnf5: **5.4.6.0** ([release/source](https://api.github.com/repos/rpm-software-management/dnf5/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of RPMs by repository/architecture; generate and sign a coherent RPM-MD snapshot; retain existing package signatures.

## Consume and source support

DNF and yum-compatible invocation consume local/remote/replica repositories; provide explicitly advertised auxiliary metadata consistently.

## Resolution policy

snapshot-owner per RPM repository

## Format-specific integrity and metadata

Preserve updateinfo/comps and module metadata when present in mirrored snapshots; local module metadata can be ingested/validated rather than synthesized. Never mix a signed index from one generation with another generation’s bytes.

## Explicit non-goals

RPM build execution and automatic construction of distro modular streams are excluded; no legacy yum2 client claim.

## Required client scenarios

- [ ] Ingest signed RPMs, refresh metadata and install a dependency using DNF/yum-compatible client flow.
- [ ] Tampered repomd or package signature fails; concurrent snapshot updates and replicas keep reference integrity.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

Native: `DELETE Packages/{file}.rpm` deletes after republishing repodata without the package.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

# F12 — Hugging Face contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Hub-compatible model/dataset metadata and HTTP resolve/download subset used by hf_hub_download and snapshot_download.

- huggingface-hub: **2.2.0** ([release/source](https://pypi.org/pypi/huggingface-hub/json)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of a complete model/dataset file tree with immutable revision and optional branch/tag pointers; no Hub commit API claim.

## Consume and source support

Repo info/tree and HEAD/GET resolve routes support standard model/dataset downloads, ETags, revision pinning and byte ranges across local/remote/replica sources.

## Resolution policy

package-owner per repo type/name; revision-bound file tree

## Format-specific integrity and metadata

Cache authorized private/gated content only under the configured upstream entitlement and feed ACL. Resolve signed external URLs internally; advertise standard HTTP transfer instead of pretending to implement Xet.

## Explicit non-goals

Hub social/inference/training/Spaces APIs, Git pushes, native Xet CAS and general Hub upload APIs are excluded. Models and datasets remain in scope.

## Required client scenarios

- [ ] snapshot_download a versioned multi-file model and dataset, then resume a large file from replica while source is offline.
- [ ] Missing file or unauthorized gated content prevents complete snapshot success; no cross-credential cache disclosure.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

Ref delete (`ant-ref`) is a ref tombstone gated by the delete permission and a `denied` policy; commits are immutable and cannot be deleted. Version deletion is unsupported.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

# F17 — Eclipse p2 contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

p2 metadata/artifact repositories, XML/JAR index representations, composite repository descriptors and installable units.

- eclipse: **4.41.0 / R-4.41-202608281142** ([release/source](https://www.eclipse.org/lists/eclipse-dev/msg12580.html)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of a validated p2 repository or IU/artifact bundle; generate a consistent repository snapshot without changing signed JAR bytes.

## Consume and source support

p2 director installs a selected IU and dependencies from local, remote mirror/cache or replica snapshots.

## Resolution policy

snapshot-owner per p2 repository

## Format-specific integrity and metadata

Composite child references are scoped and materialized for offline full seed; retain classifier/id/version relationships. Preserve upstream signed artifacts and compressed index semantics.

## Explicit non-goals

Legacy Pack200 transformation, general Eclipse marketplace APIs and building plugins are excluded initially; reject fixtures requiring unimplemented transforms.

## Required client scenarios

- [ ] Install an IU with dependencies using p2 director and repeat from seeded offline replica.
- [ ] Broken child reference, unsigned substitution for a signed artifact or incomplete IU closure fails validation.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

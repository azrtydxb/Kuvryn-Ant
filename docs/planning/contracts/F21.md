# F21 — Raw contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

HTTP GET/HEAD/PUT/DELETE with range and conditional request semantics; management browse/search API.

- curl: **curl-8_23_0** ([release/source](https://api.github.com/repos/curl/curl/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

PUT streams one path to its uniquely selected local source; optional expected SHA-256/size; immutable by default, overwrite requires policy and precondition.

## Consume and source support

GET/HEAD, byte ranges, conditional retrieval and authorized listing for local/remote/replica paths.

## Resolution policy

path-owner per normalized path

## Format-specific integrity and metadata

Normalize once and reject traversal/ambiguous encodings; distinguish content type from execution. Remote URLs use configured base mapping, never arbitrary client-directed proxy targets.

## Explicit non-goals

No WebDAV, executable directory listing, archive expansion or claim that raw file storage constitutes another format.

## Required client scenarios

- [ ] PUT a large file, GET a range, HEAD/ETag revalidate and repeat through a replica.
- [ ] Reject traversal, digest mismatch and concurrent conflicting immutable PUT; cancelled upload remains invisible.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

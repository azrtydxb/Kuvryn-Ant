# F01 — Alpine APK contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

APK v2 package/index format consumed by apk-tools bundled with Alpine 3.24.2; v3 wire format is a separate future capability.

- alpine: **3.24.2** ([release/source](https://alpinelinux.org/releases/)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of .apk files with architecture/channel metadata; generate and sign APKINDEX generations with the feed key. Package bytes/signatures are preserved.

## Consume and source support

apk update/add/fetch from local, remote-cached or replica channels; architecture paths remain explicit.

## Resolution policy

snapshot-owner per channel/architecture

## Format-specific integrity and metadata

Import trusted verification keys explicitly. Remote signed indexes are preserved; a composed local repository requires explicit regeneration and its own signing identity. Do not silently extend metadata expiry.

## Explicit non-goals

No APK v3 wire-format generation claim; no operating-system image build or package compilation.

## Required client scenarios

- [ ] Publish two architectures; apk update/add selects the correct package and verifies signatures.
- [ ] Corrupt index/signature is rejected; stale remote bytes never masquerade as newly signed metadata.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

Native: `DELETE /feeds/{feed}/apk/{channel}/{arch}/{file}.apk`. Deletes the version.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

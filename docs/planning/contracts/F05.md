# F05 — Composer / PHP contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Composer 2 repository packages.json and per-package metadata-url, dist archives and source references.

- composer: **2.10.3** ([release/source](https://api.github.com/repos/composer/composer/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of composer package metadata and dist archives; validate name/version/dependency metadata and checksums. Native Composer has no registry publish command requirement here.

## Consume and source support

composer install/update with dist delivery and explicit source references through local/remote/replica feeds.

## Resolution policy

package-owner per vendor/package

## Format-specific integrity and metadata

Rewrite permitted dist URLs to authorized immutable assets; preserve external VCS references as external. A full offline replica requires a usable dist closure. Generated metadata is coherent per package.

## Explicit non-goals

Composer 1 provider-index compatibility and acting as a general VCS server are excluded initially.

## Required client scenarios

- [ ] Install a locked dependency set from a locally ingested dist and repeat offline from a seeded replica.
- [ ] A duplicate private name never falls through to a public upstream; missing dist closure prevents full-offline completion.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

## Delete and unlist (artifact core)

All deletion goes through `artifact.Service.Delete/Unlist/Relist`: delete permission, feed/namespace delete policy (`allowed`, `unlist_only`, `denied`, immutable releases), audit and outbox in the same transaction, replication tombstones, cache invalidation hook; bytes are only reclaimed later by garbage collection.

API only (Composer has no delete): `DELETE ingest/{vendor}/{name}/{version}`. Deletes.

Management API: `DELETE /api/v1/feeds/{id}/packages/{component}/versions/{version}?action=delete|unlist|relist`, `DELETE /api/v1/feeds/{id}/assets/{asset}`, MCP `delete_package_version`, console package drawer.

# F25 — Terraform contract

Status: Defined for implementation; not yet conformance-tested. Revision 1, 2026-10-18.

## Client and protocol baseline

Terraform provider and module registry protocols with host service discovery, versions, provider platform downloads and module source retrieval.

- terraform: **v1.16.6** ([release/source](https://api.github.com/repos/hashicorp/terraform/releases/latest)).

Pin actual downloaded artifact digests in the conformance fixture lock; these are deliberately selected baseline versions, not a promise of all historical or future clients.

## Publish / ingest

Admin ingestion of provider binaries/checksums/signatures and module archives; validate namespace/name/provider/version/platform coordinates.

## Consume and source support

terraform init resolves provider and module dependencies through local/remote/replica registry endpoints.

## Resolution policy

package-owner per provider or module address

## Format-specific integrity and metadata

Feed-specific hostname binds discovery and credentials. Preserve provider signing material; module download references resolve to authorized immutable archives. Full offline seeds require materialized referenced sources.

## Explicit non-goals

Terraform Cloud workspace/state/run APIs and executing providers/modules server-side are excluded.

## Required client scenarios

- [ ] Initialize a configuration with one provider and one module for two platforms, including checksum/signature files.
- [ ] Reject substituted provider bytes, incorrect signing metadata or incomplete module closure; replica works offline.

All [shared source, cache, auth, lifecycle, search, replication and conformance requirements](common.md) also apply. Task T1 closes contract definition only; T2–T4 remain implementation and evidence work.

# Configuration reference

Kuvryn Ant is configured through environment variables. This page lists every `ANT_*` variable the server and its subcommands read, with its default, the accepted range and the matching Helm value where the chart has one. The authoritative sources are [`internal/config`](https://github.com/azrtydxb/Kuvryn-Ant/tree/main/internal/config) and the files under [`cmd/ant`](https://github.com/azrtydxb/Kuvryn-Ant/tree/main/cmd/ant).

## How configuration is loaded

- All variables are read once at process start. Changing a value requires a restart (with the chart, `helm upgrade` rolls the pod).
- Values are validated before the server opens its listener. An invalid value stops startup with a message naming the variable; secret values are never printed.
- `ant diagnostics` writes the effective, redacted configuration (passwords, keys and credentials are replaced with `[REDACTED]`).
- An unset or empty variable means "use the default". Several retention and pressure variables are overrides of settings stored in PostgreSQL: when they are unset, the value edited in the console stays in control.
- In Helm, variables without a dedicated value can be set through [`extraEnv`](../install/helm.md#values-reference). The chart only accepts names that start with `ANT_`. Do not use `extraEnv` for a variable the chart already sets, because the container would get the variable twice.

Durations use Go syntax (`90s`, `15m`, `6h`). Booleans accept `true`/`false`/`1`/`0`.

## Core

| Variable                      | Default                                                       | Allowed values                                                                                                                                                                                                     | Helm value                                                    | Description                                                                                                                                                                                                                                                                                       |
| ----------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Empty resolves the instance created by `ant bootstrap`. While no instance exists the server polls every 2 seconds and reloads in-process once one is bootstrapped.                                                                                    |
| `ANT_DATA_DIR`                | `.local/data` (binary), `/var/lib/ant/data` (container image) | absolute or relative path                                                                                                                                                                                          | fixed `/var/lib/ant/data`                                     | Private data directory: disk blobs, upload staging, S3 resume state. | `ANT_SHUTDOWN_TIMEOUT`        | `15s`                                                         | `1s` to `1m`                                                                                                                                                                                                       | `shutdownSeconds`                                             | Drain time for in-flight requests after SIGTERM/SIGINT.                                                                                                                                                                                                                                           |
| `ANT_MAX_REQUESTS`            | 32 per CPU, clamped to 128 to 1024                            | 1 to 4096                                                                                                                                                                                                          | `maxRequests` (0 = default)                                   | Concurrently admitted requests. Overflow answers `503` with `Retry-After: 1`. `/health/live` is never counted.                                                                                                                                                                                    |
| `ANT_UPLOAD_SLOTS`            | 2 per CPU, clamped to 4 to 32                                 | 1 to 256                                                                                                                                                                                                           | `uploadSlots` (0 = default)                                   | Concurrent uploads admitted per package format.                                                                                                                                                                                                                                                   |
| `ANT_TRUSTED_PROXIES`         | empty (trust no forwarding headers)                           | comma-separated CIDRs or single addresses                                                                                                                                                                          | `trustedProxies`                                              | Reverse proxies whose `X-Forwarded-For` and `X-Real-IP` headers are believed. | `ANT_TRUSTED_PROXY_CIDRS`     | empty                                                         | same as above                                                                                                                                                                                                      | none                                                          | Legacy name of `ANT_TRUSTED_PROXIES`, read only when `ANT_TRUSTED_PROXIES` is empty.                                                                                                                                                                                                              |
| `ANT_UPSTREAM_CA_MAP_FILE`    | empty                                                         | JSON object, at most 64 KiB, at most 32 entries                                                                                                                                                                    | `upstreamCA.existingSecret` or `upstreamCA.existingConfigMap` | Operator-provided map of CA IDs to PEM files, for example `{"corp-ca":"/etc/ant/ca/corp.pem"}`. "Per CPU" means `GOMAXPROCS`, which the Go runtime derives from the container's CPU limit. With the chart's default limit of 4 CPUs the defaults are 128 requests, 32 database connections and 8 upload slots per format.

The Helm chart mounts the map and the PEM files from a Secret or ConfigMap with `upstreamCA.existingSecret` or `upstreamCA.existingConfigMap`; see [Upstream CA bundles](../install/helm.md#upstream-ca-bundles).

## Database

| Variable                     | Default                        | Allowed values                                      | Helm value                                   | Description                                                                                                                                                                                                                                                              |
| ---------------------------- | ------------------------------ | --------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ANT_DATABASE_URL`           | none (required)                | libpq/pgx connection string (URL or key/value form) | `postgres.existingSecret`, `postgres.dsnKey` | PostgreSQL 17 or 18 connection string. Never logged. Use `sslmode=verify-full` in production. See [PostgreSQL](../install/postgresql.md).                                                                                                                                |
| `ANT_DB_MAX_CONNS`           | 8 per CPU, clamped to 16 to 64 | 4 to 500                                            | `dbMaxConns` (0 = default)                   | Maximum size of the connection pool of one process. Keep it below the server's `max_connections`, with headroom for `kubectl exec` commands such as `ant backup`, which open their own pool.                                                                             |
| `ANT_DATABASE_PASSWORD_FILE` | empty                          | path                                                | none                                         | Read by the container entrypoint ([`deploy/entrypoint.sh`](https://github.com/azrtydxb/Kuvryn-Ant/blob/main/deploy/entrypoint.sh)), not by the binary: the file's content is exported as `PGPASSWORD`. Used by the Compose setup; the chart passes the full DSN instead. |

The pool connects with a 5-second connect timeout and keeps no idle minimum. Standard libpq environment variables such as `PGPASSWORD` and `PGSSLROOTCERT` are honoured by the pgx driver when the DSN omits them.

| `ANT_STORAGE_BACKEND`        | `disk`                          | `disk`, `s3`                                                                                   | `storage.backend`                                                   | Blob backend used until the first storage migration. | `ANT_S3_CA_FILE`             | empty                           | PEM file, at most 1 MiB                                                                        | `storage.s3.caExistingSecret`, `storage.s3.caKey`                   | Extra CA certificates added to the system pool for the S3 endpoint. When region, bucket and credentials file are all set, the S3 backend is initialised even if `ANT_STORAGE_BACKEND=disk`, so that a storage migration can target it. See [Storage](../install/storage.md).

## Identity providers

| Variable               | Default | Allowed values            | Helm value                                        | Description                             |
| ---------------------- | ------- | ------------------------- | ------------------------------------------------- | --------------------------------------- |
| `ANT_OIDC_CONFIG_FILE` | empty   | JSON file, at most 64 KiB | `auth.oidc.existingSecret`, `auth.oidc.configKey` | File-based OIDC browser login provider. |

## Maintenance, retention and storage pressure

| Variable                          | Default                 | Allowed values                   | Helm value                                               | Description                                                                                                            |
| --------------------------------- | ----------------------- | -------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `ANT_GC_INTERVAL`                 | `6h`                    | `0` (disabled) or `1m` to `720h` | `maintenance.gcInterval`                                 | Interval of the background retention, garbage-collection and integrity worker. `ant gc` stays available when disabled. |
| `ANT_GC_GRACE`                    | `24h`                   | `1m` to `2160h`                  | `maintenance.gcGrace`                                    | Minimum age of an unreferenced blob before GC marks it.                                                                |
| `ANT_GC_DRY_RUN`                  | `false`                 | boolean                          | `extraEnv`                                               | Report what scheduled GC would delete without deleting.                                                                |

| `ANT_INTEGRITY_BATCH`             | `200`                   | 1 to 100000                      | `extraEnv`                                               | Blobs checked per integrity-scan batch.                                                                                |
| `ANT_INTEGRITY_MAX_BYTES`         | `1073741824` (1 GiB)    | at least 1048576                 | `extraEnv`                                               | Bytes read per integrity-scan run.                                                                                     |
| `ANT_RETENTION_DEFAULT_ENABLED`   | unset (console setting) | boolean                          | `extraEnv`                                               | Overrides whether the instance default retention policy is enabled.                                                    |
| `ANT_RETENTION_DEFAULT_KEEP_LAST` | unset (console setting) | 1 to 1000000                     | `extraEnv`                                               | Overrides the instance default "keep last N versions".                                                                 |
| `ANT_RETENTION_DEFAULT_MAX_AGE`   | unset (console setting) | `1h` to `876000h`                | `maintenance.defaultPolicy.maxAge`                       | Overrides the default maximum age of remote-cached content.                                                            |
| `ANT_RETENTION_DEFAULT_MAX_IDLE`  | unset (console setting) | `1h` to `876000h`                | `maintenance.defaultPolicy.maxIdle`                      | Overrides the default maximum idle time (since last access) of remote-cached content.                                  |
| `ANT_PRESSURE_ENABLED`            | unset (console setting) | boolean                          | `maintenance.pressure.enabled` (only `true` is rendered) | Overrides whether storage-pressure eviction is enabled.                                                                |
| `ANT_PRESSURE_HIGH_PERCENT`       | unset (console setting) | 1 to 99                          | `maintenance.pressure.highPercent`                       | Usage that starts eviction of least-recently-used cached content.                                                      |
| `ANT_PRESSURE_LOW_PERCENT`        | unset (console setting) | 1 to 99, below the high mark     | `maintenance.pressure.lowPercent`                        | Projected usage at which eviction stops.                                                                               |
| `ANT_PRESSURE_INTERVAL`           | `5m`                    | `0` (disabled) or `1m` to `24h`  | `maintenance.pressure.interval`                          | Interval of the periodic pressure check.                                                                               |
| `ANT_PRESSURE_SWEEP_GRACE`        | `15m`                   | `1m` to `24h`                    | `maintenance.pressure.sweepGrace`                        | Wait before a blob freed by eviction is swept.                                                                         |

The chart renders `ANT_PRESSURE_ENABLED`, `ANT_PRESSURE_HIGH_PERCENT`, `ANT_PRESSURE_LOW_PERCENT` and `ANT_STORAGE_CAPACITY_BYTES` only when `maintenance.pressure.enabled` is `true`. With `enabled: false` nothing is rendered and the console setting stays in control; it does not force eviction off. See [Storage maintenance](../operations/storage-maintenance.md).
